## Featured Project: OmniShell

[OmniShell](https://github.com/OmniKingDev/OmniShell) is an early Unix-style shell written in C and my current primary public project.

It demonstrates experience with:

- process creation and control using `fork()`, `execvp()`, `wait()`, and `waitpid()`
- signals, pipes, file descriptors, and command parsing
- shell builtins, external command execution, and GNU Readline
- Bash integration testing, compiler/linker debugging, and technical documentation

OmniShell also includes **OmniRun**, an early builtin for quickly running simple single-file Python, C, and C++ programs.
